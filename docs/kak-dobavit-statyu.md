# Как добавить статью в блог

Одна статья — один файл в папке `src/content/blog/`. Имя файла станет адресом статьи, поэтому пишем его латиницей через дефис: `kredit-posle-bankrotstva.md` → `pravperspektiva.ru/blog/posledstviya/kredit-posle-bankrotstva/`.

## Шаблон

Скопируйте блок ниже в новый файл и замените текст.

```markdown
---
title: Можно ли взять кредит после банкротства
description: Закон не запрещает кредиты после банкротства, но 5 лет нужно сообщать о нём банку. Объясняем, как банки к этому относятся.
rubric: posledstviya
summary: да, закон не запрещает брать кредиты после банкротства. Но в течение 5 лет нужно сообщать банку о том, что вы прошли процедуру.
date: 2026-11-15
faq:
  - q: Через сколько лет можно взять ипотеку?
    a: Закон не устанавливает срок. В течение 5 лет нужно сообщать банку о банкротстве, решение принимает банк.
---

## Что говорит закон

Текст раздела. Ссылки на закон — так: (п. 1 ст. 213.30 закона № 127-ФЗ).

> **Важно.** Так оформляется выделенный блок.

## Следующий раздел

- пункт списка
- ещё пункт
```

## Поля

| Поле | Что писать |
|---|---|
| `title` | Заголовок статьи |
| `description` | 1–2 предложения для выдачи Яндекса, до 160 знаков |
| `rubric` | одна из: `posledstviya`, `procedura`, `mfc`, `dolgi`, `imushchestvo`, `semya` |
| `summary` | короткий ответ — показывается под заголовком после слова «Коротко:» |
| `date` | дата публикации, `ГГГГ-ММ-ДД` |
| `updated` | (необязательно) дата обновления |
| `faq` | (необязательно) вопросы и ответы внизу статьи |
| `draft: true` | (необязательно) статья не публикуется, пока стоит эта строка |

## Правила текста

- Никаких гарантий: не пишем «спишем все долги», «гарантированно», «без последствий».
- Ссылки на нормы — по актуальной редакции 127-ФЗ.
- Без имён клиентов.

## Как опубликовать

1. Пришлите текст Claude — он оформит файл и выложит его. Или:
2. На github.com откройте репозиторий → папка `src/content/blog` → **Add file → Create new file**, вставьте шаблон, нажмите **Commit changes**. Через пару минут статья появится на сайте автоматически.

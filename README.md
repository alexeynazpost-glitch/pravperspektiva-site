# Правовая перспектива — сайт

Статический сайт на [Astro](https://astro.build): банкротство физлиц и ИП, Сергиев Посад и Московская область.

**Правила хранилища**
- Здесь только код и тексты сайта. Персональных данных клиентов здесь нет и быть не должно: заявки с сайта уходят в Яндекс Облако.
- Пароли и ключи сюда не кладём. Ключи Яндекс Облака — только в GitHub → Settings → Secrets.

## Как устроено

| Что | Где |
|---|---|
| Общие данные: телефон, адрес, реквизиты, цены, меню | `src/data/site.ts` |
| Кейсы | `src/data/cases.ts` |
| Вопросы и ответы | `src/data/faq.ts` |
| Страницы городов | `src/data/cities.ts` |
| Страницы | `src/pages/` (имя файла = адрес страницы) |
| Статьи блога | `src/content/blog/*.md` — инструкция в `docs/kak-dobavit-statyu.md` |
| Стили | `src/styles/global.css` |
| Сборка и выкладка | `.github/workflows/deploy.yml` |

Пока переменная `PUBLIC_NOINDEX` не равна `0`, сайт закрыт от поисковиков (robots.txt и метатег noindex).

## Команды

```
npm ci          # установить зависимости
npm run dev     # открыть сайт локально
npm run build   # собрать в папку dist/
```
